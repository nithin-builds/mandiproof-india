# MandiProof India

Verifiable, searchable, self-expiring crop-price bulletins for Indian farmers and buyers, powered by Arkiv Tiramisu.

- Live app: https://mandiproof-india.blondharp2.chatgpt.site
- Public reads through the Arkiv TypeScript SDK
- Wallet-signed, readonly price-quote entities
- Indexed crop, state, mandi, price and posting-time attributes
- Native 1/3/7-day expiry

## Run locally

```bash
npm install
npm run dev
```

Publishing requires an injected EVM wallet configured for Tiramisu and funded with test GLM. Demo cards are explicitly labelled illustrative until live entities exist.
